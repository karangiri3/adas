# AI Travel Friend 🌍✈️

A premium AI-powered travel planning web application built for hackathon. Enter your destination, budget, duration, travel style and interests — and get a personalized itinerary generated by Gemma 4 via Google's Gemini API.

## Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Python 3, Flask
- **AI**: Google Gemini API (Gemma 4 model)

## Project Structure

```
gemma Hackathon/

├── backend/
│   ├── app.py

```

## Prerequisites

- Python 3.10+
- A Google Gemini API key — get one free at [aistudio.google.com](https://aistudio.google.com/apikey)

## Setup

### 1. Clone the repo

```bash
git clone https://github.com/<your-username>/adas.git
cd adas
```

### 2. Set up environment variables

```bash
cp .env.example .env
# Edit .env and add your GEMINI_API_KEY
```

### 3. Create a virtual environment and install dependencies

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

pip install -r requirements.txt
```

### 4. Run the backend

```bash
# From inside the backend/ folder with venv active
python app.py
```

The Flask server starts at `http://127.0.0.1:5000`.

### 5. Open the frontend

Open `index.html` directly in your browser (no build step needed):

```
# Just double-click index.html, or use Live Server in VS Code
```

## Environment Variables

| Variable | Description | Default |
|---|---|---|
| `GEMINI_API_KEY` | Your Google Gemini API key | *(required)* |
| `GEMMA_MODEL` | Gemma model ID | `gemma-4-26b-a4b-it` |

## API

### POST `/api/plan-trip`

**Request:**
```json
{
  "destination": "Goa",
  "budget": 15000,
  "duration": "4 Days",
  "travel_style": "Adventure",
  "interests": ["Beaches", "Food", "Photography"]
}
```

**Response:** Structured JSON itinerary with days, budget breakdown, top places, food recommendations, and travel tips.

## Testing the API

```bash
curl -X POST http://127.0.0.1:5000/api/plan-trip \
  -H "Content-Type: application/json" \
  -d '{"destination":"Goa","budget":15000,"duration":"4 Days","travel_style":"Adventure","interests":["Beaches","Food"]}'
```
